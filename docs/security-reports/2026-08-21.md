## Findings

### :red_circle: CRITICAL (Immediate action required)

**CRITICAL-1: Starlette 0.50.0 — CVE-2026-48710 (Authentication Bypass)**

- **Installed:** 0.50.0 (via FastAPI 0.128.1)
- **Fixed in:** 1.0.1
- **Latest:** 1.6.0
- **Detail:** The "BadHost" vulnerability allows unauthenticated attackers to bypass path-based security middleware by injecting a malformed character into the HTTP Host header. Affects all versions from 0.8.3 through 1.0.0. This directly undermines WineBox's authentication middleware.
- **Fix:** Upgrade FastAPI to a recent version (~0.141.x) which pulls in Starlette >= 1.0.1.

**CRITICAL-2: PyJWT 2.12.1 — CVE-2026-48526 (Authentication Bypass)**

- **Installed:** 2.12.1
- **Fixed in:** 2.13.0
- **Detail:** An algorithm-confusion vulnerability lets an attacker sign a forged JWT using a public JWK string as an HMAC symmetric secret, bypassing authentication entirely. The current pin `>=2.12.0` addressed CVE-2026-32597 (crit header bypass), but 2.12.1 remains vulnerable to this newer CVE.
- **Fix:** Bump lower bound to `>=2.13.0` in `pyproject.toml` and run `uv lock`.

**CRITICAL-3: python-multipart 0.0.28 — CVE-2026-53539 (CPU DoS)**

- **Installed:** 0.0.28
- **Fixed in:** 0.0.30
- **Detail:** Quadratic-time querystring parsing with semicolon separators allows a handful of concurrent requests to exhaust all worker processes. Directly impacts FastAPI form handling (scan, record, import upload, price capture).
- **Fix:** Bump lower bound to `>=0.0.30` in `pyproject.toml` and run `uv lock`.

**CRITICAL-4: cryptography 46.0.7 — CVE-2026-69247 (Bleichenbacher Oracle)**

- **Installed:** 46.0.7
- **Fixed in:** 50.0.0
- **Latest:** 50.0.0
- **Detail:** PKCS#7 decryption functions leak information through distinguishable error paths and timing differences, enabling a Bleichenbacher oracle against RSA content-encryption keys. The current pin `>=46.0.7` fixed CVE-2026-39892 and CVE-2026-34073, but this newer CVE requires 50.0.0. The package is also 4 major versions behind latest.
- **Fix:** Bump lower bound to `>=50.0.0` in `pyproject.toml` and run `uv lock`.

### :orange_circle: WARNING (Address within 1 week)

**WARNING-1: Pillow 12.2.0 — CVE-2026-59203 (DoS via EPS parsing)**

- **Installed:** 12.2.0
- **Fixed in:** 12.3.0
- **Latest:** 12.3.0
- **Detail:** Infinite loop when parsing crafted EPS files causes denial of service. WineBox processes user-uploaded images, so a malicious EPS file could hang a worker.
- **Fix:** Bump lower bound to `>=12.3.0` in `pyproject.toml` and run `uv lock`.

**WARNING-2: Admin panel `escapeHtml()` missing quote character escaping**

- **File:** `winebox/admin/static/js/admin.js` lines 56-61
- **Detail:** The admin panel's `escapeHtml` function uses the `textContent`/`innerHTML` trick which escapes `<`, `>`, `&` but NOT `"` and `'`. When escaped values are placed inside HTML attributes (lines 184, 193: `data-user-id`, `data-user-email`), quote characters in the value could break out of the attribute. The main app's `escapeHtml` at `winebox/static/js/app.js:3585-3596` properly escapes all five characters.
- **Mitigation:** Risk is low because `user.id` is a hex ObjectId and `user.email` is validated by `EmailStr`, plus the admin panel is IP-restricted. However, defense-in-depth recommends matching the main app's implementation.
- **Fix:** Update the admin `escapeHtml` to also escape `"` to `&quot;` and `'` to `&#039;`.

**WARNING-3: Hardcoded test passwords in screenshot scripts**

- **Files:**
  - `scripts/check_url_hashes.py` line 39: `password = "TestPassword123!"`
  - `scripts/screenshot_checkin_enrichment.py` line 32: `TEST_PASSWORD = "TestPassword123!"`
  - `scripts/screenshot_import_tab_order.py` line 53: `password = "TestPassword123!"`
- **Detail:** These utility scripts hardcode test passwords rather than reading from environment variables. Per CLAUDE.md: "NEVER hardcode credentials... in source code — not in scripts." These are for throwaway test accounts against local/OAT, not production credentials.
- **Fix:** Read password from `WINEBOX_TEST_PASSWORD` env var with a clear error if not set.
- **Status:** Carried forward from 2026-05-03 review.

**INFO-4: Password strength validation is length-only (8 characters minimum)**

- **File:** regstack's `PasswordStr` type (min_length=8, max_length=128)
- **Detail:** Acceptable per NIST SP 800-63B guidance (which discourages complexity rules).
- **Status:** Carried forward from 2026-05-11 review.

**INFO-5: `cairosvg` dependency appears unused**

- **File:** `pyproject.toml` line 48
- **Detail:** `cairosvg>=2.9.0` is not imported anywhere in the codebase. Keeping an unused dependency increases attack surface.
- **Status:** Carried forward from 2026-05-17 review.

**INFO-6: nginx `client_max_body_size` mismatch with import upload limit**

- **Files:** `deploy/nginx-winebox.conf:191` (10M), `winebox/routers/import_router.py:143` (25 MB)
- **Detail:** Uploads between 10-25 MB will fail with nginx 413 before reaching the application.
- **Status:** Carried forward from prior reviews.

**INFO-7: Unbounded `.to_list()` calls in owner-scoped queries**

- **Files:** `winebox/routers/bottles.py:190`, `winebox/services/cellar_event_view.py:242`, `winebox/services/cellar_debit.py:142`, `winebox/services/cellar_inventory.py:88`
- **Detail:** Several `.to_list()` calls without a `length` parameter could return unbounded results. All affected queries are scoped to a single user's data, limiting blast radius, but a user with a very large cellar could cause memory pressure.
- **Recommendation:** Add a `length=MAX_USER_RESULTSET` parameter for defense-in-depth.

**INFO-8: `datetime.utcnow()` usage in non-production code**

- **Files:** `scripts/migrations/migrate_sqlite_to_mongo.py` (lines 264-265, 375, 416, 440-441, 465-466), `tests/test_wine_ownership.py` (lines 39-40, 52-53)
- **Detail:** Uses deprecated timezone-naive `datetime.utcnow()` instead of `datetime.now(timezone.utc)`. These are a one-time migration script and test file, so low severity.
- **Status:** Carried forward from prior reviews.

**INFO-9: Home IP address in version-controlled allowlist**

- **Files:** `deploy/winebox-admin.toml` lines 12, 19; `CLAUDE.md` line 141
- **Detail:** The operator's home IP `109.255.27.13` is in the git-tracked admin allowlist. This is intentional by design (the TOML file is the source of truth), but represents a minor information leak.
- **Status:** Carried forward from prior reviews.

**INFO-10: Reference data endpoints lack rate limiting**

- **File:** `winebox/routers/reference.py`
- **Detail:** The reference data router (wine types, grape varieties, regions, classifications) has no rate limiting. These are read-only public lookup endpoints, but could be used for data scraping. The X-Wines endpoints do have rate limits (120/min on search, 10/min on export).
- **Recommendation:** Add rate limits to reference endpoints for consistency.

**INFO-11: Import schemas accept arbitrary dict values**

- **File:** `winebox/schemas/import_schemas.py` lines 15, 78, 93
- **Detail:** `preview_rows: list[dict[str, Any]]` and `rows: list[dict[str, Any]]` accept arbitrary dicts. This is by design for user-defined import column structures. Row count is bounded (`max_length=500` per chunk, `max_length=5` for previews). Values are used only as data, never as query operators.

### :green_circle: CLEAN (Passed review)

| Area | Status |
|------|--------|
| **Hardcoded secrets** | No real secrets in source code. `.gitignore` properly covers `.env`, `secrets.env`, `*.pem`, `*.key`, `*.p12`, `*.pfx`. No secrets in git history. |
| **Authentication & authorization** | All 60+ user-data endpoints use `RequireAuth`. All admin endpoints use `RequireAdmin`. |
| **Data isolation (owner_id)** | Every database query for user-owned data filters by `owner_id` or `cellar_id`. |
| **NoSQL injection** | No unsafe operators (`$expr`, `$where`, `$function`). No user input interpolated into query operators. All regex from user input uses `re.escape()`. |
| **ObjectId parsing** | All `ObjectId()` calls on user input wrapped in `try/except`. |
| **Input validation** | All API inputs use Pydantic models. Form fields have `max_length`. Search queries capped at 200 chars. Numeric fields have `ge`/`le` bounds. |
| **File upload security** | Magic-byte validation, size limits (10 MB images, 25 MB spreadsheets), UUID filenames, extension allowlists. |
| **Path traversal** | `_safe_resolve()` validates all file paths. UUID-generated filenames prevent user-controlled paths. |
| **Rate limiting** | Comprehensive coverage: auth (5-30/min), scan (20/min), search (120/min), export (10/min), import (10/min), enrichment (20/min), admin (30/min). |
| **JWT security** | Argon2id password hashing. JWT with `jti` for revocation. Blacklist checking. Bulk revocation via `tokens_invalidated_after`. 120-minute TTL. |
| **Token invalidation** | Password changes and resets invalidate all existing tokens. |
| **Security headers** | `X-Content-Type-Options`, `X-Frame-Options: DENY`, CSP (no unsafe-inline), HSTS (2 years), `Referrer-Policy`, `Permissions-Policy`, `X-Permitted-Cross-Domain-Policies`. |
| **CORS** | Defaults to empty origin list (same-origin). Explicit allowlist when configured, never `*`. |
| **No inline scripts** | All `<script>` tags use `src` attributes. CSP `script-src` is `'self'`. |
| **Debug mode** | Disabled in production. Startup validator blocks production with debug=on. OpenAPI docs disabled outside debug mode. |
| **HTTPS enforcement** | HSTS at nginx layer. `enforce_https` set in production config. Startup validator warns if disabled. |
| **TLS configuration** | TLS 1.2+1.3 only, strong cipher suites, session tickets disabled. |
| **MongoDB security** | Connection uses authentication (from env). Bounded timeouts (5s/10s/30s). Production database safety check prevents non-production hosts from connecting. |
| **Third-party APIs** | All Anthropic API calls have explicit timeouts (60-120s). PostHog API key loaded from env. DigitalOcean API has 30s timeout. |
| **Sensitive data logging** | No passwords, tokens, secrets, or API keys logged. |
| **API data exposure** | No `hashed_password` or `owner_id` in API responses. Admin hides MongoDB hostname. Export strips internal fields. |
| **Git history** | No secrets ever committed. Last 30 commits are security reports and workflow cleanup only. |
